Your server is up and running smoothly

The server is stable as of the latest check (Aug 13, 2026), but it was a bumpy day. LordCloud moved the server to a new host address again (now in-100.lordcloud.ovh) - the join address playminecraft.in hasn't been rechecked against it yet, so treat it as unconfirmed until that happens. A live-map add-on (Pl3xMap) was installed and immediately caused the server to crash and restart itself over and over, about once a minute - most likely because it briefly pushed memory usage over the server's limit. It's been removed and the server has been stable since, but it revealed that memory usage is already close to the ceiling even without it, worth keeping in mind before adding anything else. Separately, the two world-terrain add-ons (Geophilic and Tectonic) that were installed weeks ago but never actually worked turned out to be sitting in the wrong folder the whole time - that's now fixed and confirmed loading on a freshly regenerated world. The one earlier watch item, a near-minute freeze during a routine world save (most likely a slow-disk hiccup on the host), hasn't recurred in the newest logs but also hasn't been actively chased down yet. Players can build, earn in-game currency, complete daily tasks, mine for skill levels, travel around the map, trade with each other, and more. A small update is ready to install when you give the go-ahead (see "Coming Next" above).

What the colors mean

Every item on this dashboard is tagged with one of five labels, shown as a colored dot and pill:

Finished — done and confirmed working Live — running on the real server, but still being double-checked Not Started — on the list, work hasn't begun Needs A Decision — waiting on you to choose or approve something Stuck — can't move forward until something else is fixed

Right now

Danger Zone deaths & fight rules fixed - built, not uploaded yet

Two changes, built and ready but not yet on the live server: dying inside the safe Sanctum will now let you keep your full inventory, while dying out in the Badlands still drops your items as normal - that's the actual risk of living out there. Separately, the in-game rules text about fighting was wrong (it said fighting was off everywhere); it's now corrected to explain that fighting only works in the Badlands, and only when both players are out there together. Neither change affects the Coin fee already charged on death, which still applies everywhere. Needs a full build and an upload/restart before players see either change.

Money & rewards rebalance, now with Farming - deployed, needs a restart

Daily task rewards were badly out of balance - two of the "hard" tasks paid less Coins than an "easy" one - so all mining tasks were repriced around one fixed rule: turning in a stack of Cobblestone always pays 50 Coins, with Normal tasks paying 1.5x that and Hard tasks 2.5x that. That uncovered a loophole (buying Stone and smelting it could out-earn a task), so that one task was swapped for a mining-only task that can't be bought around. Shop prices, claim-land prices, and the Coin fee on death were all scaled up to match. The Daily Board now guarantees a set mix of easy/normal/hard tasks every single day in every category, instead of hard tasks only showing up sometimes by chance - and a brand new Farming category just went in alongside Mining (harvest crops, breed animals, brew potions, fill your claim with crops), plus new food items in the shop. Existing players' Coin balances were reset to zero a second time rather than migrated, at your request, since testing since the last reset had already started earning again. One thing was deliberately left undecided rather than guessed at: whether the Renown currency should get a real way to earn it, or be retired in favor of just using Coins for land slots - that's still an open question for you. This is uploaded to the server now, but the server needs a restart before any of it takes effect - the automatic remote-restart attempt failed (same connection issue noted below), so this needs the manual restart button in the LordCloud panel.

What we're working on

Waiting on a server restart to bring the money/rewards/Farming rebalance above online, then getting version 1.24.1's remaining pieces double-checked in-game: an easier point-and-click menu for the Mining skill, a friendlier task menu (click a category to see its tasks, empty categories show "Coming soon"), and a smarter travel safety check that lets you confirm a risky teleport instead of just blocking it.

What players can already do

Accept the server rules and get a short welcome tour; earn Coins and Renown; claim and protect land; complete daily tasks; level up a Mining skill; travel around the map and visit friends; trade, buy from the shop, and check leaderboards; use crafting stations; and step into the risk/reward "Danger Zone."

Land & building (Claims)

Players can protect their builds. The system now clearly shows which protected blocks came from playtime, which were bought with Coins, and how many extra "plots" (claim slots) a player has unlocked.

Custom icons & look

A custom icon pack is live so Coins, Renown, and task menus show proper icons instead of plain text. Confirmed working from real screenshots.

Bigger, more varied terrain (fixed Aug 13)

The Geophilic and Tectonic world-generation add-ons were installed weeks ago but never actually worked - they'd been uploaded to the wrong folder on the server the whole time. That's now fixed and confirmed working on a freshly regenerated world. Next step is running the pregeneration tool across the full map so the new terrain is ready before players explore it.

Long-term world plan

We're building one big shared world split into a protected "Sanctum" (safe building, no player-vs-player fighting) and an outer "Badlands" (riskier area with fighting allowed and tougher monsters).

Getting ready to open to the public

The join address (playminecraft.in) was confirmed reachable as of 2026-08-09, but the server has since moved to a new host address again (2026-08-13) and the domain hasn't been rechecked against it yet - treat it as unconfirmed for now. Still open: a branded welcome message (MOTD), fixing the whitelist so it actually matches the "public from day one" plan (it currently blocks non-whitelisted players), confirming backups are running, and one full test of the new-player experience with an actual client.
